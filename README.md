# 貓咪照顧小幫手

> 記得每一餐。算準每一口。遇見對的貓。

以照顧兩隻貓的真實需求為出發點，解決飼主日常的照顧痛點。

## 功能

- **每日照顧**：可新增多隻貓（名字、照片、品種），每隻貓有自己的待辦清單與時間，打勾隔天自動重置
- **長週期提醒**：驅蟲、剪指甲、疫苗等可自訂週期與日期，自動計算下次日期
- **食量計算**：依靜止能量需求（RER）公式計算每日熱量與飼料克數
- **AI 品種配對**：規則式專家系統，依 10 個生活習慣問題推薦最適合的品種
- **品種百科**：28 個品種的體型、壽命、個性、照顧重點與常見遺傳疾病

## AI 運作方式

品種配對採用規則式專家系統（Rule-based Expert System）：

- **知識庫**：每個品種 11 項特徵分數（1–5 分）
- **推論規則**：每個答案對應一條規則與權重
- **推論引擎**：`符合度 = Σ(權重 × 特徵符合度) ÷ Σ權重`，排序後輸出前五名並說明原因

## 資安與隱私

- 使用者輸入以 `textContent`／`value` 寫入，避免 XSS
- 數值與日期皆有範圍驗證；從瀏覽器讀回的資料會逐項檢查格式
- 不收集個資，資料只存在使用者自己的瀏覽器，可一鍵清除
- 自訂照片只在瀏覽器內裁切縮小、去除 GPS 等隱藏資訊，不上傳

## 技術

純 HTML、CSS、JavaScript，單一檔案，無外部程式庫。字體使用 Google Fonts 思源宋體（Noto Serif TC）。
